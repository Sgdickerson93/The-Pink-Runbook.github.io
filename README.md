# Pink tech portfolio

Open index.html in a browser to preview. No dependencies or build needed.

Edit index.html for visible text and contact links, style.css for the palette and layout, and script.js for blog posts, project details, and resume text. All personal details and projects are samples.

GitHub Pages: create YOUR-USERNAME.github.io, upload these extracted files to the root, commit, then Settings > Pages > Deploy from a branch > main > / (root) > Save. Do not upload only the ZIP.
